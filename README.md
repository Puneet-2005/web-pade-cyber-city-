# CityPunks - Cyberpunk Landing Page

A futuristic cyberpunk-themed landing page built using pure HTML, CSS, and JavaScript.

## Preview

A visually immersive landing page featuring:

- Neon cyberpunk UI design
- Animated hero section
- Floating debris particle effects
- Custom SVG character artwork
- Interactive buttons and hover animations
- Responsive layout
- Feature showcase section

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG Graphics
- Google Fonts

## Features

### Hero Section
- Full-screen immersive cyberpunk background
- Animated floating character
- Neon glow visual effects
- Scanline overlay for futuristic aesthetics
- Animated scroll indicator

### Navigation Bar
- Minimal futuristic navigation menu
- Interactive hover effects
- "Play Now" CTA button

### Interactive Effects
- Floating debris particle generation
- Smooth animations
- Hover transitions
- Character floating animation

### Features Section
- Responsive card layout
- Game-style feature showcase
- Modern typography
